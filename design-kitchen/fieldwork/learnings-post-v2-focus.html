Frontend Feb 5, 2026 Exp. #05

Audio player refactor

Key takeaway Working software beats clever software.

removed: webamp · added: custom unified player

Initially integrated Webamp because the UI matched the site aesthetic. Looked great in isolation.

Integration into a React SPA was the problem. Five days. StrictMode double-mounts, orphaned DOM, dual audio engines, R2 CORS skips.

Removed Webamp. One Howler instance across all routes. Playback persists through navigation.

Lost visual flair. Gained stability.

"Working software beats clever software every time."

Learnings / Expedition #05

Audio player refactor

FR-2026-02-05
classified: public
Executive summary Webamp removed after 5 days of React integration issues. Replaced with unified Howler.js engine. Trade-off: less visual flair, more stability.

01 — Background

removed: webamp · added: custom unified player

Webamp matched the retro aesthetic. Classic winamp UI, playlists, visualizer.

02 — Findings

  • Renders to document.body — bypasses React
  • StrictMode double-mount orphans DOM nodes
  • Dual audio engines on route change
  • R2 + CORS track skips

03 — Resolution

Single global Howler instance. Playback persists across routes. Track list from /api/tracks.

04 — Conclusion

Working software beats clever software every time.

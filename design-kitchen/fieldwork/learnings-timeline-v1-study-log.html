Frontend Feb 5, 2026 Expedition #05

Audio player refactor

Key takeaway Working software beats clever software. One global Howler instance beat five days fighting Webamp + React StrictMode.

Removed Webamp. Added a custom unified player. Playback persists across routes; R2 tracks load via /api/tracks.

Lost some visual flair. Gained stability and sanity.

Expedition #04 Feb 5, 2026 Infra

Site wiring guide

Key takeaway Each service does one job: Hostinger (registrar), Cloudflare (DNS + R2), Vercel (app), R2 (media).

mossyrealm.space → Cloudflare → Vercel. media.mossyrealm.space → R2. Most of the work is waiting for nameserver propagation.

Design Jan 16, 2026 Expedition #03

Cursors & effects experiment

Key takeaway Dense retro layouts need simple interactions. More effects ≠ better vibes.

Sparkles, fireflies, wax-seal cursors — reverted all of it. Complexity lives in the layout, not the behavior.

Expedition #02 Dec 2025 Design

Sunlit glade palette

Key takeaway Warm amber + forest green = cozy. Cool blue + green = clinical.

Six palettes explored. Amber accents gave the "sunlight through trees" feeling.
